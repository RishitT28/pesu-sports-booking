================================================================================
PES UNIVERSITY ATHLETICS ADMINISTRATION - RESTRICTED ACCESS VAULT
================================================================================

This directory contains the central sports database (pesu_sports.db),
the email notification agent configuration (email_config.json), and
encrypted student credentials.

ACCESS CONTROLS:
- For Common Users: Direct modification is locked and restricted.
- For Admin Access: Run "Open_Locked_Folder.bat" and provide the master
  passkey (Default: 123).
- For Application Access: The PESU Sports Booking Web Server, the Admin
  Database Desktop App, and the Email Configuration Agent possess the
  master encryption key to transparently read/write records.

FILES IN THIS VAULT:
1. pesu_sports.db          -> SQLite database storing Bookings, Queues, Students
2. email_config.json       -> SMTP settings and automated notification triggers
3. Open_Locked_Folder.bat  -> Password-protected vault explorer launcher
================================================================================
